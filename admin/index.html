Connect to GitHub

This page saves new projects by committing directly to your site's repository. It needs a GitHub token with write access, generated once and stored only on this device.

How to generate a token
1. Go to github.com/settings/tokens?type=beta and click "Generate new token".
2. Name it anything, e.g. "Portfolio Admin".
3. Under "Repository access", choose "Only select repositories" and pick portfolio.
4. Under "Permissions" → "Repository permissions", set Contents to "Read and write".
5. Generate the token and paste it below. It will start with github_pat_.
